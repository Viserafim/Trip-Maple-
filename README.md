# TripMate V2

Versão nova do TripMate baseada na versão estável do projeto anterior.

## Mudanças desta V2
- Interface em vermelho e branco inspirada no Canadá.
- Roteiro simplificado, sem ícones individuais por dia.
- Removida a função Mover dia.
- Cada dia pode ser editado diretamente.
- Atividades podem ser adicionadas, editadas e excluídas.
- Salvamento local no aparelho.
- PWA preparado para iPhone e GitHub Pages.

## GitHub Pages
Este projeto foi preparado considerando um repositório chamado `Trip-Mate-V2`. Se usar outro nome, ajuste as referências `/Trip-Mate-V2/` em `manifest.webmanifest`, `src/main.jsx` e `src/styles.css`.
